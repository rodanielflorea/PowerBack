What this app does

An always-on-top, screen-capture-invisible assistant window for live interviews / meetings. Two main use cases:

  • Solo: load ChatGPT/Claude in the window, transcribe what's being said into the chat input via Voice or Caption mode.
  • Speaker + Supporter: two computers connected over LAN. Speaker (A) is in the meeting; Supporter (B) listens in and helps via voice + chat. Optional VB-Cable relay so the meeting peer (C) hears B speaking through A's mic.

Glossary used below: A = speaker (you, in the meeting). B = supporter (helper on another machine). C = the remote person on Zoom/Meet/Teams/etc.

Quick start (solo)

  1. Setup → pick Caption or Voice mode.
  2. If using Voice: Voice tab → choose engine (OpenAI Whisper API or local whisper.cpp) and provide key/paths.
  3. Sites tab → add https://chatgpt.com or https://claude.ai.
  4. Click Start.
  5. For Caption mode: a screen-area selector appears — drag a rectangle around the live caption strip you want to OCR.
  6. Click the ● rec dot in the header to begin / stop.

Quick start (speaker + supporter)

On A's machine (Speaker):

  1. Setup → Speaker (host), port 2000, click Start.
  2. For meeting relay: install VB-Cable (free, click Get VB-Cable in the Network tab), reboot, then pick CABLE Input in Network → Virtual mic output.
  3. In your meeting app (Zoom/Meet/etc.) set the microphone to CABLE Output.

On B's machine (Supporter):

  1. Setup → Supporter (client), address A's-IP:2000, click Start.
  2. The chat panel becomes the main view. Speak, type messages, drop images.

The header bar

Everything you need during a session lives in the thin header. Reading left to right:

  • Network pill (e.g. LIVE, CONNECTING, --): current connection state. Green = connected; amber = trying; gray = idle.
  • Opacity slider: hover and drag horizontally to fade the window 0–100%. Useful for one-handed peeking. Hotkeys Ctrl+Alt+] / Ctrl+Alt+[ also work.
  • ▾ — switch site (preset URL dropdown).
  • ↻ — reload the loaded site. Also force-shows the webview if it ever gets stuck hidden.
  • ⚙ — open Settings.
  • ● rec dot — start/stop the active mode (Voice or Caption). Pulsing red = running.
  • Stealth shield — green check = invisible to screen capture; red slash = visible. Click to toggle.
  • Mic pill (Supporter only) — cycles B's mic between 🔇 MUTE, 🔒 TO A, 📢 TO A+C. See "Mic modes" below.
  • End — stops the session and returns to Setup. Confirms first.
  • − hides the window (bring it back with Ctrl+Alt+H).
  • × quits the app entirely.

Drag the empty area between header items to move the window. Header items have -webkit-app-region: no-drag so they stay clickable.

Setup screen

Before each session, the Setup overlay walks through the five tabs:

  • Essentials — pick active mode (Caption / Voice) and network role (Speaker / Supporter). Speaker shows the port; Supporter shows the address. Use Save default to remember the value across launches.
  • Sites — URLs that appear in the rail dropdown during the session. Add ChatGPT, Claude, etc.
  • Caption — OCR language and poll interval. The capture area itself is picked after Start.
  • Voice — transcription engine + mic + system audio sources.
  • Network — max supporters cap (Speaker only).

Click Start to enter the live session. Click End in the header to come back here.

Voice mode

Captures your mic and/or system audio, chunks it ~5 s at a time, transcribes via Whisper (cloud or local), and pastes the result into whichever app is foreground via clipboard + Ctrl+V. Use it for relaying spoken meeting content into a chat editor in another app.

Setup

  1. Voice tab → pick microphone, toggle "Capture mic" / "Capture system audio".
  2. Pick engine:
    • OpenAI Whisper API — paste API key. Easy, fast, audio leaves your machine.
    • Local whisper.cpp — browse to whisper-cli.exe and a model (ggml-base.bin etc.). Fully offline; slower without GPU.
  3. Pick language or leave on Auto-detect.

Use it

  1. Click into the target app's input box first (chat, editor, anything that takes paste).
  2. Press Alt+C or click the ● dot. After ~5–8 s the transcript appears in your target app.

⚠ While running, don't click into this app or the paste will land here. Stealth shield does not block the paste mechanism — the foreground window is whatever you click last.

Caption mode (OCR)

OCRs a screen rectangle (live video captions, embedded subtitles, anything text-shaped), word-diffs against what was already sent, and types the new portion directly into the chat input of the loaded AI site — no clipboard, no focus theft.

Setup

  1. Set Active mode to Caption.
  2. Set OCR language and poll interval (700 ms default is a good balance).
  3. Optionally enable Show red border around the OCR area while capturing — a thin pulsing red frame appears over the captured rectangle. Off by default to stay subtle; the frame itself is screen-capture-invisible.
  4. Click Start. The window hides briefly — drag a rectangle around the caption area you want to OCR.
  5. Press Alt+C or click the ● dot to begin streaming.
  6. Press Ctrl+Q any time to re-pick the area without stopping the session.

Smaller, tighter rectangles produce cleaner OCR. Avoid backgrounds with similar-color text. The diff includes a smart cleanup pass that strips repeated phrases and OCR artefacts like <Error>.

Speaker + Supporter mode

Two computers connected over LAN. A (Speaker) is the one in the meeting. B (Supporter) listens in and helps. C is the remote person on the meeting platform.

What's shared automatically

  • A's mic + system audio → B (so B can hear what A and C are saying).
  • B's mic → A (so A hears B's whispered guidance through their own headset).
  • Two-way audio is always on — there's no toggle to disable it.

Chat panel (B's main view)

When B connects, the AI website is hidden and the chat panel takes over. B can:

  • Type messages and press Enter to send.
  • Drag-drop or paste images (auto-resized, >5 MB warns).
  • Click the 📎 attach button to pick a file.

Everything B sends shows up on A's Sticky note window.

Sticky note (A's helper window)

A small white window with a yellow header that floats next to the main window on A's machine. It receives every chat message from B (text and images), preserves history, and:

  • Has the same stealth + opacity behavior as the main window.
  • Hide / show with Ctrl+Left / Ctrl+Right.
  • Position is remembered across launches.
  • CLEAR button wipes the visible history (local + remote).

1:1 supporter limit

Only one B can be connected at a time per Speaker. Additional connection attempts are rejected (close code 4002 = capacity, 4003 = duplicate IP). The Network tab shows the connected supporter and a Kick button (close code 4000 — kicked clients won't auto-reconnect).

Mic modes (B's microphone routing)

The mic pill in B's header cycles through three states. The currently active state is also shown as a colored banner above the chat panel.

⚠ In TO A+C, the meeting peer hears B's voice as if it came from A. Use deliberately. The pill turns red and the banner pulses to make this unmistakable.

VB-Cable setup (relay to meeting app)

To make C hear A (or B in 📢 mode) through Zoom / Meet / Teams, you need a virtual audio cable that loops the app's audio output back as a virtual microphone input.

  1. Network tab → click Get VB-Cable. Download & install (free, restart required).
  2. After reboot, Network tab → pick CABLE Input (VB-Audio Virtual Cable) in "Output device".
  3. In your meeting app (Zoom / Meet / Teams), set the microphone to CABLE Output (VB-Audio Virtual Cable).
  4. Click Test cable (1s tone) — you should see the meeting app's mic level jump.

If you start a session without VB-Cable installed, a banner appears at the top of the window with a one-click installer link. Dismiss it once and it stays dismissed for the session.

HELP ME hotkey

If A presses Win+Shift+/ (the default for "Help request"), B's machine pops up a full-screen HELP ME!!! alert with a 3-tone beep. Use this to grab B's attention if they wandered off mid-meeting.

Click the alert (or press the dismiss button) to clear it.

Stealth from screen capture

The shield icon enables setContentProtection. On Windows this hides the window from:

  • OBS / display capture in screen recorders
  • Zoom / Teams / Meet share-screen
  • Win+PrtScn and most screenshot tools
  • The capture-area red overlay (when enabled) is also stealth-protected

It does not defeat:

  • Hardware capture cards
  • A phone / camera pointed at the screen
  • Some kernel-level monitoring agents

Toast notifications & banners

Brief slide-in messages in the bottom-right communicate state changes:

  • Mic-mode changes (with color matching the new mode).
  • Network connect / disconnect / kick events.
  • VB-Cable warnings (file too large, device missing).
  • Errors that don't warrant a modal (transcription failures, OCR errors).

Toasts auto-dismiss after a few seconds. The mic-mode banner above the chat panel is persistent — it's always showing the current mode.

Auto-update

The app uses GitHub Releases for updates. Settings → App version → Check for updates manually, or wait for the on-launch check. When an update is downloaded, the Restart & install button appears.

Troubleshooting

I can't see the loaded website

Click ↻ in the header (or press Ctrl+R) — it force-shows the webview and reloads the page. The webview gets hidden whenever Settings or Setup is open; if a flow ever leaves it hidden, reload fixes it.

B can't hear A's mic / system audio

Check that A's Voice tab has both "Capture mic" and "Capture system audio" enabled. Verify the network pill shows LIVE on both sides. On A's machine, the loopback capture sometimes needs Windows to re-enumerate devices — toggle the recording dot off/on.

C (meeting peer) can't hear me

Make sure VB-Cable is installed, "CABLE Input" is selected as Output device in Network tab, and the meeting app's mic is set to "CABLE Output". Click Test cable — if no level appears in the meeting, the routing is broken.

Voice mode pastes into the wrong app

Click the target app's input field before starting Voice mode. While the dot is pulsing, don't click into this app.

Caption mode duplicates text

The diff is word-based and tolerant to OCR variations, but if the OCR engine produces wildly different text for the same speech, some duplication is unavoidable. Press Ctrl+Q to re-pick a tighter area — smaller and cleaner is better.

OpenAI 401 / 429 errors

Check the Log tab. 401 = bad API key. 429 = rate limit / out of credits.

Local whisper exits with non-zero code

Open a terminal and run the same command manually with -f some.wav -m model.bin to see the real error. Ensure the model and exe are from the same whisper.cpp version.

Hotkey shows red "register failed"

Another app already owns that combo system-wide. Pick a different one.

Sticky note isn't appearing on A's screen

Press Ctrl+Right to force-open it. If it's off-screen (e.g. after a monitor change), the saved position may be invalid — close it and reopen, or move the main window then reopen sticky.

Supporter keeps reconnecting after I kick them

Kick uses close code 4000 which suppresses auto-reconnect on the client. If they reconnect anyway, they likely opened a fresh app instance — ban by IP isn't implemented, only by session.
