Quick start

  1. Open General tab → add a URL like https://chatgpt.com or https://claude.ai.
  2. Click the ▾ on the left rail and pick the site.
  3. Pick a mode (Voice or Caption) under General → Active mode.
  4. Configure that mode's tab (engine + key for Voice; pick area for Caption).
  5. Click the ● dot on the rail to start. Click again to stop.

The window

  • Drag anywhere on the empty header to move the window.
  • Opacity slider: hover and slide your cursor across it — no clicking needed. Cursor X position = opacity 0–100%.
  • Stealth dot: green = invisible to screen capture / recorders / meeting share-screen. red = visible. Click to toggle.
  • − hides the window (use the toggle hotkey to bring it back, default Ctrl+Alt+H).
  • × quits the app.

The rail (left side)

▾ — switch site (preset URL dropdown)
↻ — reload the loaded site (also force-shows the webview if it ever gets stuck hidden)
⚙ — settings (this dialog)
● — start/stop the active mode (gray = idle, pulsing red = running)

Voice mode

Listens to your microphone and/or system audio, transcribes in ~5-second chunks, and pastes the text into whichever app is foreground via clipboard + Ctrl+V. Useful for relaying spoken meeting content into a chat editor in another app.

Setup (Voice tab)

  1. Audio capture: pick a microphone and choose which sources to capture (mic + system loopback by default).
  2. Transcription engine:
    • OpenAI Whisper API — needs an API key. Easy, accurate, audio leaves your machine.
    • Local whisper.cpp — needs whisper-cli.exe and a model file (ggml-base.bin etc). Fully offline. Slower without GPU.
  3. Pick a language or leave on Auto-detect.

Use it

  1. Switch to Voice mode under General → Active mode.
  2. Click into the target app's input box (Notepad, chat, editor — anything that accepts paste).
  3. Click the ● dot. After ~5–8 s, transcribed text appears in your target.

⚠ While running, do not click into this app or the paste will land here.

Caption mode

OCRs a screen rectangle (e.g. video captions in a browser), removes already-pasted text via word-level diffing, and inserts the new portion directly into the chat input of the loaded site (ChatGPT / Claude). No clipboard, no foreground stealing.

Setup (Caption tab)

  1. Click Select next to "Capture area".
  2. The window hides → a transparent overlay covers your screen.
  3. Drag a rectangle around the caption area.
  4. Pick OCR language and poll interval (700 ms is a good default).

Use it

  1. Switch to Caption mode under General → Active mode.
  2. Pick the AI site in the rail dropdown ▾.
  3. The chat input is auto-focused; click it once if needed.
  4. Click the ● dot — new caption text streams into the chat input as it appears.
  5. Press your Reset capture area hotkey (default Ctrl+Q) anytime to re-pick the area without stopping.

Stealth from screen capture

The green dot enables setContentProtection. On Windows this hides the window from:

  • OBS / display capture in screen recorders
  • Zoom / Teams / Meet share-screen
  • Win+PrtScn and most screenshot tools

It does not defeat:

  • Hardware capture cards
  • A phone / camera pointed at the screen
  • Some kernel-level monitoring agents

Troubleshooting

I can't see the loaded website

Click the ↻ reload button on the rail — it force-shows the webview and reloads the page. The webview gets hidden whenever Settings is open; if a flow ever leaves it hidden, reload fixes it.

Voice mode pastes into the wrong app

Click the target app's input field before starting Voice mode. While the dot is pulsing, don't click into this app.

Caption mode duplicates text

The diff is word-based and tolerant to OCR variations, but if the OCR engine produces wildly different text for the same speech, some duplication is unavoidable. Press your reset hotkey (Ctrl+Q) to re-pick a tighter area — smaller and cleaner is better.

OpenAI 401 / 429 errors

Check the Log tab. 401 = bad API key. 429 = rate limit / out of credits.

Local whisper exits with non-zero code

Open a terminal and run the same command manually with -f some.wav -m model.bin to see the real error. Ensure the model and exe match the same whisper.cpp version.

Hotkey shows red "register failed"

Another app already owns that combo system-wide. Pick a different one.
